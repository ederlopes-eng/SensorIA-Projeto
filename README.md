# SensorIA - Projeto

Integração e análise de dados de sensores meteorológicos aplicados à engenharia.
Disciplina: Inteligência Artificial e Programação para Engenharia.

## Conjunto de dados
- Fonte: INMET - Instituto Nacional de Meteorologia (BDMEP)
- Estação automática: Bertioga - SP, código A765
- Latitude: -23,84472221 | Longitude: -46,14333333 | Altitude: 5 m
- Data de fundação da estação: 01/02/2017
- Período: 01/01/2025 a 31/12/2025 (8.760 registros horários, 19 colunas)
- Formato: CSV delimitado por ponto e vírgula, decimal com vírgula, codificação Latin-1
- Ajuste realizado: remoção das 8 linhas de metadados do cabeçalho original,
  para que a primeira linha contenha os nomes das colunas.
